# SPEC — HIP-3 builder-deployed perps (engine rules)

Source (fetched + verified WIB 2026-10-08):
- hip-3-builder-deployed-perpetuals.md

## Quoted rules
- Staking requirement 500k HYPE, expected to fall over time; maintaiined
  >= 183 days after dex deployment; above-requirement stake can unstake.
- One perp dex per deployer meeting the requirement. Independent margining,
  order books, deployer settings per dex.
- First 3 assets in a dex free; additional assets via a shared Dutch auction
  (same hyperparams as HIP-1: 31h, initial = 2x last price, floor 500 HYPE).
- Fee share 0-300%. Above 100%: protocol fee raised to equal the deployer fee.
- haltTrading: cancels all orders, settles positions to current mark. Same
  action resumes trading (recycles the asset).
- Per-dex backstop liquidator at 0x400..00 + dex_index; only accepts
  cross-margin-enabled assets; falls back to ADL for solvency.
- Deployer slashing: stake-weighted validator vote; guidelines 100%/50%/20%.
  Slashed stake is BURNED. (v1 sim: halt misuse -> slashable vote stub.)

## Engine mapping
- PerpDex: {name, deployer, staked_hype, deploy_ts, fee_share_bps, halted:
  {coin: bool}, assets: [coin...]}.
- Assets gain a dex namespace: coin id "dex:COIN"; books/clearing keyed by
  full id; marks per full id.
- can_open / liq / backstop for dex assets route the backstop to
  vault_hlp_dex_<name>; fee split routes fee_share_bps to the deployer
  (share above 100% raises the taker fee itself).
- haltTrading(coin): cancel all book orders, force-settle every position at
  mark (realized to balances), flag halted; resume clears the flag.
- Dutch auction: shared auction state {asset_name, end_ts, start_px};
  current px = start_px decaying linearly to 500 HYPE over 31h; deploy action
  pays the current px (HYPE not modeled as money -> stake accounting only).
- Staking: stake action locks deployer HYPE-count; deploy checks stake >= 500k
  and (block_ts - deploy_ts) >= 183d before unstake of the requirement amount.
